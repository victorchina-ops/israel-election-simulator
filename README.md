# סימולטור בחירות 2026

[פתיחת הסימולטור](https://victorchina-ops.github.io/israel-election-simulator/?view=1&tab=dashboard)

סימולטור אינטראקטיבי בעברית המבוסס על נתוני הסקרים והנחות המודל שבתוכו. אפשר לשנות את שקלול הסקרים, הרכב הגושים ושיעורי ההצבעה, ולבחון את תוחלת המנדטים, סיכויי המעבר וסיכויי הרוב של כל גוש.

- חישוב אחוז החסימה, באדר–עופר והסכמי העודפים מחדש בכל הדמיה.
- אפשרות לטעות בסקרים מופעלת תמיד בממשק.
- תוחלות מנדטים ורווחי סמך 95% לשגיאת האמידה מההרצות.
- תצוגת 100 ריבועים, לוגואים ותוחלות לכל מפלגה; ייצוא גרפים ונתוני תרחיש.

החישובים מתבצעים בדפדפן. שינוי הפרמטרים של מבקר אינו משנה את התרחיש של מבקרים אחרים או את הקבצים במאגר. אפשר גם להוריד את `index.html` ולהפעיל מקומית.

## פירוש התוצאות

הנתונים המצורפים מעודכנים ל־12 בספטמבר 2026; הם אינם מתעדכנים אוטומטית. מקורות, שיטות והנחות מפורטים בסימולטור. אלה תוצאות מותנות בהנחות, ולא הבטחה לתוצאת הבחירות. רווחי הסמך של התוחלות מודדים שגיאת מונטה־קרלו; הם אינם טווח תוצאות הבחירות האפשריות. תוחלת מפלגה כוללת גם אפס מנדטים בהרצות שבהן לא עברה את אחוז החסימה.

הסמלים מוצגים לצורך זיהוי הרשימות, ושייכים לבעליהם. צבעי הגושים משקפים את השיוך שנבחר בתרחיש.

## אירוח ועדכון

האתר מתפרסם באמצעות GitHub Pages מקובץ HTML עצמאי. כדי לעדכן את האתר, מחליפים את `index.html` בגרסה הניידת החדשה שנבדקה ושומרים את השינוי במאגר.
